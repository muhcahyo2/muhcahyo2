# Real-time Collaboration Whiteboard

A powerful collaborative whiteboard for remote teams to brainstorm and work together in real-time.

## Features

- Real-time drawing and collaboration
- Video chat integration
- Multiple drawing tools (pen, shapes, text, sticky notes)
- Infinite canvas with zoom and pan
- Export to PNG/PDF
- Session recording and playback

## Technical Stack

- React with TypeScript
- Socket.io for real-time communication
- WebRTC for video chat
- HTML5 Canvas API for drawing
- MongoDB for session storage
